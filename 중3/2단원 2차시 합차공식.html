다항식의 곱셈 공식 (2)

★ 지난 시간 복습

1. $(a+b)(c+d) = ac+ad+bc+bd$

2. $(a+b)^2 = a^2 + 2ab + b^2$

3. $(a-b)^2 = a^2 - 2ab + b^2$

3. 합차 공식: (합) × (차)

$(a+b)(a-b) = a^2 - ab + ba - b^2$

$= a^2 - b^2$

💡 기억법: 가운데 $ab$항이 서로 사라지고 제곱의 차만 남는다!

4. $(x + a)(x + b)$ 의 전개

$(x+a)(x+b)$

$= x^2 + bx + ax + ab$

$= x^2 + (a+b)x + ab$

$x$의 계수

두 수의 합

상수항

두 수의 곱

5. 계수가 1이 아닌 경우 (보너스)

$(ax+b)(cx+d)$

$= acx^2 + adx + bcx + bd$

$= acx^2 + (ad+bc)x + bd$
