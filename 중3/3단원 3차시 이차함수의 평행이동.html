• \(y = ax^2\)의 평행이동

점: \((u, \ au^2)\)

1) \(y\)축으로 \(q\)만큼 평행이동

점: \((u, \ au^2 + q)\)

\(x \xrightarrow{\text{\small 제곱}} x^2 \xrightarrow{\ \times a\ } ax^2 \xrightarrow{\ + q\ } ax^2 + q\)

\(\Rightarrow\ y = ax^2 + q\)

2) \(x\)축으로 \(p\)만큼 평행이동

점: \((u+p, \ au^2)\)

\(\begin{cases} u+p \xrightarrow{\ -p\ } u \xrightarrow{\text{제곱}} u^2 \xrightarrow{\ \times a\ } au^2 \\[1.2em] x \longrightarrow x-p \xrightarrow{\text{제곱}} (x-p)^2 \xrightarrow{\ \times a\ } a(x-p)^2 \end{cases}\)

\(\Rightarrow\ y = a(x-p)^2\)

• \(y = f(x)\)의 평행이동

점: \((u, \ f(u))\)

1) \(y\)축으로 \(q\)만큼 평행이동

점: \((u, \ \underbrace{f(u) + q}_{y})\)

\(\Rightarrow\ y - q = f(x)\)

2) \(x\)축으로 \(p\)만큼 평행이동

점: \((\underbrace{u + p}_{x}, \ f(u))\)

\(\Rightarrow\ y = f(u) = f(x-p)\)
