2. 완전제곱식과 대입의 원리

(a + b)² = (a + b)(a + b)
= a² + ab + ba + b²
= a² + 2ab + b²
b 대신 -b를 대입
(a - b)² = { a + (-b) }²
= a² + 2a(-b) + (-b)²
= a² - 2ab + b²

원리: 합의 제곱식을 알고 있다면, b 자리에 (-b)를 대입하여 차의 제곱식을 바로 유도할 수 있다.
