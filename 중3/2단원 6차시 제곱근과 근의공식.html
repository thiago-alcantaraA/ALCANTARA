4. 이차방정식의 풀이 (2)

제곱근을 이용한 풀이

1. 기본형 : $x^2 = k$

\( x = \pm \sqrt{k} \)

2. 변형 : \((x+p)^2 = k\)

\(x+p = \pm \sqrt{k}\)

\( x = -p \pm \sqrt{k} \)

완전제곱식 만들기

① \(x^2\)의 계수를 \(1\)로 만들기

② 상수항을 우변으로 이항

③ 양변에 \( (\frac{x \text{계수}}{2})^2 \)를 더하기

④ \((x+p)^2 = k\) 꼴로 고치기

이 과정은 근의 공식의 토대가 됨!

근의 공식 유도와 완성

일차방정식 \(ax+b=0\) 의 해 : \(x = -\frac{b}{a}\)

※ 근의 공식 유도 과정 (\(ax^2+bx+c=0\))

1. 양변을 \(a\)로 나누기 : \(x^2 + \frac{b}{a}x + \frac{c}{a} = 0\)

2. 상수항 이항 : \(x^2 + \frac{b}{a}x = -\frac{c}{a}\)

3. 양변에 \((\frac{b}{2a})^2\) 더하기 : \(x^2 + \frac{b}{a}x + (\frac{b}{2a})^2 = \frac{b^2}{4a^2} -\frac{c}{a}\)

4. 완전제곱식으로 정리 : \((x + \frac{b}{2a})^2 = \frac{b^2 - 4ac}{4a^2}\)

5. 제곱근 구하기 : \(x + \frac{b}{2a} = \pm \frac{\sqrt{b^2 - 4ac}}{2a}\)

이차방정식의 근의 공식

\( x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \)

※ 근의 공식 하나면 모든 이차방정식을 풀 수 있다!
