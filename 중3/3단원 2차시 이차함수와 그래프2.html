\(y = x\) \((0,0), \ (1,1)\)

\(y = ax\) \((0,0), \ (1,a)\)

\(y = x\)의 그래프의 변형

1) \(|a| \uparrow\) → \(y\)축과 가까워진다.

2) \(|a| \downarrow\) → \(x\)축과 가까워진다.

\(y = x^2\) \((0,0), \ (\pm1,1)\)

\(y = ax^2\) \((0,0), \ (\pm1,a)\)

\(y = x^2\)의 그래프의 변형

1) \(|a| \uparrow\) → 폭이 좁아진다.

2) \(|a| \downarrow\) → 폭이 넓어진다.
