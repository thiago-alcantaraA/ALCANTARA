1-2. 제곱근의 성질과 대소 비교

중3 수학 판서

복습 : 근(根) → '해'

$x^2 = \Box$ 는 방정식

↳ $x$는 $\Box$의 제곱근

★ 핵심 : $\sqrt{a^2} = |a|$

$a \ge 0 \longrightarrow \color{#a5f3fc}{a}$

$a < 0 \longrightarrow \color{#fca5a5}{-a}$

* $a$가 음수일 때 $-a$는 양수!

1. 제곱근의 성질 ($a > 0$)

제곱근의 정의 이용

① $(\sqrt{a})^2 = a$

② $(-\sqrt{a})^2 = a$

성질 (절댓값)

③ $\sqrt{a^2} = a$

④ $\sqrt{(-a)^2} = a$

2. 제곱근의 대소 비교

→ 핵심 전략: "모양을 통일하라!"

$\sqrt{a}$ $\sqrt{b}$

$\sqrt{a} < \sqrt{b}$

$\iff a < b$

① 둘 다 $\sqrt{\enspace}$

$\sqrt{5} < \sqrt{7}$

② 둘 다 없을 때

$3 < 5$

③ 하나만 있을 때 ★

$\sqrt{9} > \sqrt{7}$

주의! 음수가 붙으면 부등호 방향이 반대가 된다!
