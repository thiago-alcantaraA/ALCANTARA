💡 등식의 4가지 기본 성질 (a = b 일 때)
① 덧셈 성질
a + c = b + c 양변에 같은 수를 더해도 등식 성립
② 뺄셈 성질
a - c = b - c 양변에서 같은 수를 빼도 등식 성립
③ 곱셈 성질
a × c = b × c 양변에 같은 수를 곱해도 등식 성립
④ 나눗셈 성질
a ÷ c = b ÷ c (단, c ≠ 0 일 때 성립)
